Website Details

This section is about how I made this site and other small tidbits about it.

How this whole thing started was due to me wanting to work on a smaller project while I was working on cars and other bits. So I figured making a website to catalogue all of the stuff I done be it hobbies or programming might help. The whole website is built with css (a bit of javaScript for the animated background) and html through github pages and I got a template from petoKrisa on github but tweaked numerous things to fit something you'd see in a PlayStation portable/PS3 menu. I prefer this frutiger/skeumorphism aesthetic over the clean metro look partly due to nostalgia and the fact that's more popular nowadays than when it was in use but also because I dislike the "metro" overtly clean look a lot of apps have gone through.

(screenshot from original)
This is how it looked like vs now it took me awhile mainly due to me having to re-learn how to make websites again and being busy in general. At first it was rather basic with the template I got from PetoKrisa and the only thing I ended up doing was sorting out anchoring to other html pages and the navbar colouring scheme.

I was also trying to sort out how to make the PSP XMB waves inside the website. I have tried it out with some placeholder text there and you can see it doesn't look quite as good as the final version I got. Trying to do it in javaScript was a bit complicated so I had to look at how it's supposed to be done through websites like w3schools etc.

This is how it looks now and you can see that it looks a lot better and feels more like frutiger aero. Although, I might update the website later on to include other hobbies of mine when I get better with css and html since at the moment the website might seem a bit basic but hope you like what I made here all in all it took me about a month to finish this side project (I'm terrible when it comes to finishing stuff).
